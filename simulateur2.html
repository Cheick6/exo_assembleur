🔍 Sens de lecture et Syntaxe MAP32

1. La règle d'or de l'Assembleur

En MAP32 (et dans la plupart des assembleurs), une ligne de code se lit presque toujours de gauche à droite. Le format général est le suivant :

[ACTION] [MODE] [DESTINATION] [SOURCE]

■ ACTION (Opcode) : Ce que le processeur doit faire (Charger, Additionner, Sauter...).
■ MODE : Comment le processeur doit comprendre les adresses (Est-ce une adresse exacte ? Une valeur directe ?).
■ DESTINATION : Où le résultat sera sauvegardé (Généralement un registre, sauf pour STORE).
■ SOURCE : Avec quoi on fait l'opération (Une donnée en mémoire, une valeur immédiate).

Exemple : ADD Rg2 R0 R1 ➔ On Additionne (en mode 2 Registres) le contenu de R1 dans la destination R0 (R0 = R0 + R1).

2. Lexique des Modes d'Adressage (MODE)

CodeSignificationDescription
ImImmédiatLa SOURCE est une valeur brute (Ex: LOAD Im R1 1002).
DDirectLa SOURCE est une adresse mémoire exacte (Ex: ... R0 400 ➔ Lit la case 400).
IIndirectLa SOURCE est une adresse qui contient une autre adresse. C'est un pointeur de pointeur.
BBaséAdresse cible = Registre de Base (RB) + La SOURCE (Le déplacement).
Rg1/Rg2RegistreOpération impliquant 1 ou 2 registres internes.

3. Lexique des Actions (ACTION)

InstructionDescription
LOADLire : Copie une donnée depuis la mémoire vers un Registre CPU.
STOREÉcrire : Prend le contenu d'un registre et le sauvegarde dans la Mémoire RAM.
(Attention: Pour STORE, la destination est écrite à la fin de l'instruction)
ADDAdditionne la source à la destination.
NEGTransforme un nombre positif en négatif (Complément à 2).
JMPJump : Saute directement à une ligne ou une étiquette (Boucle).
JMPZ / JMPOSaut Conditionnel : Saute UNIQUEMENT si Zéro (Z) ou Overflow (O) est activé.
